# Aqua: Live Reports

https://aquareports.netlify.app: three live pages per market, each reading Supabase when it opens.

| Page | Path | Markets | Data |
|---|---|---|---|
| Booking pipeline | `/pipeline/<market>/` | all five | `public.booking_pipeline`, rewritten each morning |
| Covers pace tracker | `/<market>-pace-tracker` | London, Hong Kong, USA | pace materialised views, refreshed by pg_cron |
| Daily bookings | `/london/daily/` | London | covers view (pg_cron) and `public.london_daily_ga4`, written each morning |

The pages call four Netlify functions (`netlify/functions/`) that hold the Supabase service-role key.
`index.html` and `<market>/index.html` are generated by `build_hub.py` from `manifest.json`; never
hand-edit them. Netlify publishes only pages (`aqua/publish.py` copies them into `dist/`).

## Shared code

`aqua/config/markets.toml` holds every market, venue, account id and rule. `aqua/sources/` reads
GA4, Meta and Google Ads (through GoMarble) and SevenRooms (Supabase). `aqua/dates.py` holds the
week rules: Monday to Sunday, year on year minus 364 days.

The weekly and monthly static reports were retired on 5 November 2026; they remain in git history
(commit `f4d3a72` is the last that has them).
